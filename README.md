## The entry

`main.py` writes one line of plain text to `/output/entry.txt`: a joke about a meeting that should have been an email.

> We held a 47-minute meeting to read an email aloud, then spent ten more minutes deciding who would email everyone what the email said.

The joke is two-stage absurdity: first the group reads the email aloud for 47 minutes, then it spends ten more minutes deciding who should email everyone what the email said. The meeting's only output is an email restating the email it met about.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

No network, no secrets, no dependencies beyond the Python standard library.
